# Issues and pull requests

Carrier accepts bug reports, documentation issues, feature requests, and usage
questions through [GitHub Issues](https://github.com/Aixand/carrier/issues/new/choose).
Search existing issues first and follow the [support guide](SUPPORT.md) when
reporting a problem. Responses and fixes depend on maintainer availability.

We do not accept external pull requests because the team lacks capacity to review
and support them. This includes code changes, documentation fixes, and cleanup.
Open an issue instead of a pull request.

Report vulnerabilities privately using the [security policy](SECURITY.md).
Follow the [code of conduct](CODE_OF_CONDUCT.md) in project spaces.

For local development and validation, see the [development guide](docs/development.md).
